# Quickstart — Spark Forge Azure (EN)

Three commands:

```bash
git clone <spark-forge-azure>
cd spark-forge-azure
./setup.sh        # Windows: .\setup.ps1
```

Then, from any project:

```bash
sparkforge-azure doctor
```
