# Superpowers — congelado neste repositório

O plugin superpowers (skills universais de fluxo, como brainstorming e
planning) esta **congelado** neste repositório: nao recebe novas skills nem
mudanca de conteudo, e nao e a porta de entrada do trabalho aqui.

A razao e de escopo, nao de qualidade: este repo tem o proprio fluxo
deterministico de especificacao — o SDD em `docs/sdd/` — e skills de dominio
versionadas em `skills/` + `.claude/skills/` (as `sparkforge-azure-*`). Fluxo
novo entra pelo SDD (`sdd-define` abre a feature); skill de dominio nova entra
por `skills/<nome>/SKILL.md` com eval em `evals/`.

- **Estado**: congelado — usar, nao estender.
- **Sucessor para processo**: `docs/sdd/` (define/design/plan/build/ship).
- **Status detalhado**: `docs/superpowers/STATUS.md`.
